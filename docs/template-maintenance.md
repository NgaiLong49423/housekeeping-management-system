# Hướng Dẫn Template Đã Ngừng Áp Dụng

Repository này đã được khởi tạo thành Housekeeping Management System. Tài liệu bảo trì template bên dưới không còn áp dụng cho phát triển dự án; giữ lại để tham khảo lịch sử. Nguồn hiện hành là [README](../README.md), [AGENTS.md](../AGENTS.md), [PRD](requirements/PRD.md), [SRS](requirements/SRS.md) và [SQL Server Data Dictionary](requirements/SQL_SERVER_DATA_DICTIONARY.md).

Không dùng hướng dẫn cũ trong tài liệu này để thay đổi framework, DBMS, nhánh hay cấu trúc dự án. Hãy làm theo các tài liệu hiện hành được liệt kê ở trên.
